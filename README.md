Memory optimization mod for Minecraft

FerriteCore is one of the most popular Minecraft mods available. I put together this page to help players find reliable downloads and installation instructions.

## Installation Steps

1. Install the Fabric loader for your Minecraft version
2. Download the `.jar` file from the link above
3. Move the file into your `.minecraft/mods/` folder
4. Launch the game
